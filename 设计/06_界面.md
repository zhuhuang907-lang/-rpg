# 界面（仿崇祯模拟器，简化、无图画）

实现见 `game/public/`。

## 布局

```
┌ 顶栏：印章＋剧本名 │ 状态栏（日期 · 地点 · 名字，随醒来逐步点亮） │ 史事 起居注 历书 存档 设置 ┐
├ 数值条：五六项，各带一根细条、一个词、本回合的 ↑↓                                         ┤
├──────────────┬────────────────────────────────┬──────────────┤
│ 局势           │ 正文（开场三拍 / 本回合的场景）        │ 问人           │
│  人群满意度条  │ 上一回合结算：回报 · 账目 · 风声       │  人物卡＋召对  │
│ 地方一览       │ 案头：来报卡（类型 · 标题 · 来人 · 形式）│  回答＋采纳    │
│  （代替地图）  │ 拿主意：采纳的主意 · 大白话 · 交给谁办 │ 建议簿         │
│                │         润色 · 定下，过这一回合         │                │
└──────────────┴────────────────────────────────┴──────────────┘
```

手机上三栏变成底部的「局势 / 案头 / 问人」三个标签。

## 和崇祯模拟器的对应

| 崇祯模拟器 | 这里 |
|---|---|
| 左上角国库、内帑、民心、腐败度、威望 | 顶上数值条（按身份换项目） |
| 地图视图（灾情、民心、城防、税收） | 地方一览（文字表） |
| 大臣呈上的奏折 | 案头来报（各身份各有形式） |
| 召一到两位大臣议政 | 问人（每回合两人） |
| 诏书建议库 | 建议簿＋「采纳」 |
| 诏书润色 | 润色 |
| AI 推演、数据变化 | 结算：回报（可能失真）· 账目（真实）· 风声 |

## 刻意不做的

- 图画、地图、立绘。
- 红字提示对错。
- 正文里的考证与争论：核查结果只在「史事」面板。
