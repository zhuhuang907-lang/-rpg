# 大系统重做（需求台账 R-139、R-146）

玩家原话（2026-11-07）：「整个打仗的系统太少了……完全学习一下十字军之王和钢铁雄心，目前的战争系统基本上无法使用……经济上，财政商民身上，政治上，其他的所有系统你根本就没有做呀，你只是做了个框架而已，实际上根本就玩不了」。

## 总原则
- **能玩**：每个系统都要有「做了什么 → 几个月后怎样」的因果，有取舍（钱、人、民心、好感此消彼长），能输能赢；不能只是按钮和数字。
- **数从账上来**：人数、钱粮、物价由程序照账算；开局底数照史料由 DeepSeek 推、写依据；AI 只挑「做什么」、说缘由。
- **照身份**：一方之主、地方官、将领、商人、百姓、寨主各有各的盘子，够不着的照原史走。
- **一期一期做**：每期做完能从头玩到尾、每个按钮有真点测试，交玩家验收再做下一期。

## 第一期：战争（十字军之王 + 钢铁雄心，不要国策树）
1. **兵源**：人力池照户口和兵制（府兵、募兵、征发、八旗绿营……）定，每月慢慢回；征兵花人力、钱粮、民心。封臣照契约和对你的好感出兵（好感低的出得少、迟到）。
2. **将领**：统帅有进攻、防守、后勤、机动四项和特质（猛将、持重、善守城、骑战、贪功），打仗攒阅历、会升会死会被俘；军中有派系。
3. **攻城**（十字军之王式）：城有城防等级和存粮；围城每天涨进度，器械、兵力、主将擅攻城都加快；围城中途出事（疫病、粮尽、内应开门、城墙崩坏、守军出城突击）；可以强攻（快、伤亡大）或困守（慢、少伤亡）。
4. **占领与战争分数**：占的城按月加分，打赢的仗照规模加分；拖久了厌战，双方民心、士气往下掉；分数够了才谈得了割地、称臣。
5. **军团与战线**（钢铁雄心式）：几支军编成一路，指定守哪一线、攻哪一线，军团照命令自己布防推进；补给照路和仓，冬季、山地减员。
6. **掳掠、俘虏、赎金、人质**；议和后有停战期，期内再打名声大跌；盟友照约来援，不来的翻脸。
7. **甲械生产**：军器监、工坊出甲械，部队装备不齐打仗打折；新兵种要先有甲械。
8. **舟师**：江河渡口、水战，渡江要船。
9. 敌国照第 R-145 由 DeepSeek 扮演，上面每一样他也会用。

## 第二期：财政经济
1. 州县各自的户口、田亩、发展、产业（市集、仓廪、作坊、盐场、矿冶、窑），建一样花钱花工、几个月成、往后每月出息。
2. 预算：赋税、徭役、军费、俸禄、宫廷各有轻重，一调就看到进项、民心、军心怎么变。
3. 借贷与国债：向富商、寺院、钱庄借，有利息、到期不还名声掉、债主坐大。
4. 钱法与物价：铸钱足值减重、纸钞滥发 → 通胀；粮、盐、布、铁、茶各有价，照收成、战事、商路涨落。
5. 市场与商路：各大城一个市，货在城与城之间流，商路被兵断了物价就跳。

## 第三期：商人与百姓营生
1. 每月收支：吃穿住、工钱、地租、利息、税役，入不敷出就欠债、卖地、逃荒。
2. 买卖：照各城物价贩货，雇车船、走商队，路上有匪、关卡抽税；囤积居奇有风险。
3. 店铺、作坊雇工，田地租佃收租，放贷收息；官府、胥吏、豪强盘剥。
4. 往上走：捐纳、科举、结交官员、联姻；往下掉：破产、充军、为盗。

## 第四期：政治（十字军之王式）
1. 议事会：宰相、管财、管兵、管刑、管外交，各派一件差事，照本事出结果。
2. 封臣契约：税和兵各交几成；派系实力过三成就逼宫（要减税、要换储君、要独立），不应就反。
3. 阴谋：拉拢、离间、构陷、刺杀，有暗中进度、成功率、败露。
4. 律法：继承法、王权大小，改律法要威望、要人支持。
5. 威望、恐惧、压力：做事攒或掉，压力大了出毛病。
