# 回合循环（仿崇祯模拟器）

崇祯模拟器的一回合（一季）是：**看国势 → 接时政任务 → 问大臣 → 写诏书 → AI 推演 → 数据变化 → 新危机**。我们把这五步做成所有身份都通用的形式，只换"案头上的东西"和"问谁"。

## 回合长度

| 身份 | 一回合 | 理由 |
|---|---|---|
| 皇帝、割据者 | 一季（同崇祯模拟器） | 政令落地要几个月 |
| 官员、军将 | 一月 | 公文往返以月计 |
| 商人、士子、平民 | 一旬；遇到急事可以拆成一天一天过 | 生活节奏快、事件小 |

开场三拍不算回合，第三拍结束后进入第一回合。

## 第一步 · 看局势

侧栏顶部是一排数值条（见 03），下面是人群满意度。每个数都可以点开，看最近三回合的变化和原因，原因用一句话写成谁做了什么。

**崇祯模拟器的地图视图（灾情、民心、动乱、城防、税收）我们做不了**，改成"地方一览"表：一行一个地方，列出这几项的状况和一句话说明。

## 第二步 · 案头（对应"奏折 / 时政任务"）

每回合开头，案头上摆三到五份**来报**。每份来报的格式：

```
【来报】标题（四到八个字）
来自：谁（身份）· 以什么形式（奏折 / 公文 / 书信 / 口信 / 账单 / 传闻）
正文：用当时的口吻，80–200字。必须有具体的人、数、期限
涉及：哪几项数值、哪几个人群
期限：几回合内不处理会怎样（只写对方声称的后果，真实后果藏在 GM 笔记）
```

- 来报的口吻随来人而变：奏折文雅、迂回，口信直白，传闻夸大。**来报可以说谎、可以夸大、可以瞒报**，这是崇祯模拟器的精髓。
- 至少一份来报是上一回合决定的回响。
- 来报可以不处理，不处理也是一种决定，会进推演。

## 第三步 · 问人（对应"召大臣议政"）

- 每回合可以找**一到两个人**商量。皇帝是召对，知县是找幕友、问书吏，平民是问家人、邻里、熟人。
- 每个人都有**立场、性格、私心、记忆**（见 `04_事件系统.md` 里的人物卡）。同一件事问不同的人，给的主意不同，而且各有道理、各有隐患。
- 回答的格式：先是对话（这人的说话方式），然后在旁边列出"他的建议"一到三条。玩家可以把建议收进**建议簿**，写决定时引用。
- 他们记得你以前的决定，也记得你是不是听过他们的。

## 第四步 · 拿主意（对应"写诏书"）

- 玩家用大白话写打算怎么办。
- 有一个**"润色"**按钮，把大白话改写成符合身份的文书：诏书、批札、手书、口头吩咐。润色后的文本给玩家看、可以改，确认后才算数。
- 决定必须落到**谁去办**。没指定人，就由默认的执行人去办（皇帝是有司，知县是胥吏，平民是自己或家人）。

## 第五步 · 推演与结算（对应"AI 推演 → 数据变化"）

结算分三层呈现，顺序固定：

1. **回报**：执行的人怎么回禀，用当时的文书口吻。回报**可能失真**，执行人会把功劳揽到自己身上，把失败推给别人。
2. **账目**：一张表，列出各数值的变化和一句话原因。账目是真实的，可以和回报对照，看出谁在说谎。
3. **风声**：一到三条街谈巷议或同僚私语，透露回报里没说的东西。

**不弹红字提示。** 决定错了，玩家要从账目和风声里自己看出来。

## 第六步 · 新事（对应"新危机出现"）

结算后，从事件池抽出下一回合的来报（见 04），然后回到第一步。

## 一回合的正文总量

案头＋问人＋结算，合计**不超过1500字**。超过就分页，玩家点"下一页"才继续，不一次性倒出来。
