# 开局改版方案：从"交代一切"改成"一个人、一件事、一个坎"

## 问题在哪

现在的开局契约（`初步脚本` 里 app.js 约第1208行的提示文案，以及引擎的 GM 提示词）要求 AI 在第一段里交代完：时间（年号＋公元＋季节＋日子）、地点、你是谁、家世与处境、当朝天子与天下大势、眼下的事、在场各人的姓名神情。七件事挤进一段，结果就是堆砌：读者还没进戏，先读了一页档案。

## 新开局契约（替换原来那七件事）

1. **状态栏只占一行**，时间、地点、身份都放在这里，不写进正文：
   `熙宁元年九月十四 · 两浙路杭州钱塘县 · 周三娘，十七岁`
2. **正文不超过350字**：只写一个场景，一个人在你面前，提一件事，然后停在要你拿主意的地方。
3. **家世和天下大势不进开场**，放进侧栏"案头"：家世、天下、人物三栏，玩家点开或问起才展开，剧情用到时再带出一句。
4. **不替玩家说话，也不替玩家动作**，只写玩家感官能接收到的东西。
5. **每个身份有自己的"案头"**，开局的那件事从这里来：

| 身份 | 案头上的东西 | 开局示例（一句话钩子） |
|---|---|---|
| 皇帝 | 奏折 | 一道请赈和一道催饷同时到，户部只够一头 |
| 知县、官员 | 状纸、上司的札子 | 新到任第三天，一张告本县里正的状纸压在最上面 |
| 平民女子 | 来人、短札、家账 | 牙人捎来一页没盖官印的契（即本局第一场） |
| 商人 | 账本、货单 | 一船货在关上被扣，税务说缺一张公凭 |
| 士子 | 文会帖子、荐书 | 有人送来荐书，荐主正是被弹劾的那位 |
| 兵卒、军将 | 军令、粮册 | 粮册比点名少了三十人的口粮 |

6. **数值只显示与这个身份有关的两三项**，比如周三娘的是"奁田亩数、母亲的信任、手头的钱"，不要每个身份都摆"国库、民心"。
7. **后果要延迟、要连锁**（学崇祯模拟器）：一个决定在两到三回合后，以另一个人上门的方式回来。

## 可直接替换的提示文案

> 点下面「生成开场」，AI 只做一件事：把你放进一个具体场景里，面前有一个人带来一件事，停在你要拿主意的那一步。时间、地点和你是谁写在顶上一行；家世和天下大势放在侧栏「案头」里，需要的时候再看。
