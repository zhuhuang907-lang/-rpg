# 参考：《历史模拟器：崇祯》

> 本仓库运行环境打不开评测网站的正文，以下只基于搜索摘录。每条后面标了来源编号。

## 它是怎么呈现内容的

| 方面 | 它的做法 | 我们怎么借 |
|---|---|---|
| 核心循环 | 看国势 → 接时政任务 → 问大臣 → 写诏书 → AI 推演 → 世界数据变化 → 新危机 [1] | `02_回合循环.md` 的五步 |
| 回合 | 以季度为一回合 [5] | 皇帝一季；其他身份按节奏缩短 |
| 开局 | 屏幕中央是地图和大臣呈上的奏折；奏折里是阉党对立、盐政崩溃、税收流失、宗室兼并 [2][3] | 案头的来报；地图做不了，改成"地方一览" |
| 议政 | 每回合召一到两位大臣，选谁、怎么问、信不信，由玩家决定；同一议题换不同的人，建议截然不同 [6][8] | "问人"一步，人物卡上有立场、性格、私心、记忆 |
| 人物 | 每个 NPC 有独立的性格、立场和行为逻辑；魏忠贤代表阉党利益，对东林党给出更强硬的建议 [1][7] | 人物卡 |
| 诏书 | 自然语言写；有"润色"功能，输入关键词就扩写成完整诏书；可以把大臣的建议收进"诏书建议库" [1][4] | "拿主意"一步和建议簿 |
| 数值 | 国库、内帑、民心、腐败度、威望、市场通货 [1]；阶层满意度，农民满意度持续恶化会引发起义 [6] | `03_数值与人群.md` |
| 后果 | 不在你犯错时弹红色提示；诏书由大臣和地方层层执行，效果可能几回合后才显现 [4] | 铁律第6条；结算三层 |
| 连锁 | 一份奏折可能牵出官员站队变化、地方压力转移、军费吃紧 [9] | 回响事件 |

## 它的毛病，我们要避开

| 毛病 | 对策 |
|---|---|
| 崇祯初年的官员提到"大顺"，时间节点判断错 [3] | 铁律第7条；史事表只收已核条目 |
| 长局记忆在若干回合后出现偏差；私聊和廷议记忆不同步 [4][7] | 人物卡的"记忆"栏逐回合追加，问人时一并带入 |
| 国策效果的数值与最终奏折不一致 [6] | 账目必须真实，数和文对得上 |
| 设定偏阴谋论，明史细节不足 [10] | 事件必须有依据，虚构内容不越出制度框架 |

## 它没有、我们要加的

- **非皇帝身份**：它只有崇祯一个身份，我们的回合循环要套用到官员、军将、商人、士子、平民身上。
- **醒来式开场**：它开局直接上奏折；我们先用三拍缓冲，再进入回合。
