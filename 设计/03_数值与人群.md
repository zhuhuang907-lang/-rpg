# 数值与人群

崇祯模拟器左上角是：国库、内帑、民心、腐败度、威望、市场通货；另外还有各阶层满意度，农民满意度持续恶化就会起义。我们照这个思路给每种身份配一组数，但**每组只放这个身份真正关心的五到六项**。

## 通用规则

- 每个数都有**单位**，能用钱粮、人数、亩数表示的，一律不用百分比。抽象的（威望、信任）用0–100，并配一个词：如"冷淡/平常/亲近/倚重"。
- 每个数旁边显示本回合的变化（↑↓）和一句原因。
- 数值初值必须有依据：按史料的量级，或在 GM 笔记里写明是设定。未核实的量级不显示具体数，只显示一个词（如"拮据""宽裕"）。
- **数和文对得上**：来报、回报、对话里提到的数，与侧栏一致。

## 各身份的数值条

| 身份 | 数值条（五到六项） | 人群满意度 |
|---|---|---|
| 皇帝 | 国库（钱、粮）、内帑、民心、吏治、威望、军心 | 按朝代取：士大夫/朝官各派、宗室、宦官或外戚、军队、农户、工商 |
| 割据者、军阀 | 府库、兵额实数、粮饷可支几月、地盘、部将忠心、名分 | 部将、士人、百姓、邻近势力 |
| 官员、知县 | 官库钱粮、上官考语、民望、胥吏掌控、私财、清名 | 上司、乡绅、胥吏、小民 |
| 军将 | 兵额（册上/实有）、粮饷、士气、主帅信任、私兵 | 士卒、主帅、地方官、粮官 |
| 商人 | 本钱、存货、信用、官府关系、行内名声 | 东家或伙计、同行、官府、主顾 |
| 士子 | 学业、文名、盘缠、人脉、身体 | 师友、同年、荐主、家人 |
| 平民、家族中人 | 家资（钱、粮、田）、家中地位、名声、人情、身体 | 家人、邻里、官府差役、主家或佃户 |

## 人群满意度

- 每个人群一个0–100的数，配一个词："怨/不满/平常/安/感戴"。
- 满意度低于某个线，会**触发人群事件**（见 04），比如佃户抗租、胥吏怠工、士卒鼓噪、宗室上书。
- 人群满意度变化的原因必须能追到具体决定或具体事件。

## 示例：周三娘局

| 数值 | 初值 | 说明 |
|---|---|---|
| 手头的钱 | 一贯二百文 | 设定（三娘私房） |
| 奁田 | 三十亩 · 名下未定 | 设定 |
| 母亲信任 | 70 · 亲近 | |
| 伯父戒心 | 35 · 平常 | 越高，伯父越防着她 |
| 名声 | 60 · 平常 | 私会外人的风声会让它掉 |
| 人情 | 无 | 欠谁、谁欠你，逐条列 |

人群：母亲、伯父、佃户、外人（牙人、米铺）。
