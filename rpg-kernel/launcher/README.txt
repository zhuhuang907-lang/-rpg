历史模拟 RPG（枢引擎）· Windows 版

【怎么开始】
1. 先把整个压缩包「全部解压缩」（在压缩包上点右键）。不要在压缩包里直接双击。
2. 打开解压出来的文件夹，双击「启动游戏.exe」。会先弹出「正在启动」小窗，几秒后打开游戏窗口。
   · 第一次运行，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   · 如果 exe 还是打不开：双击「一键启动.bat」（会开一个黑窗口，那就是游戏服务，别关它），
     然后在浏览器里打开 http://127.0.0.1:8787
3. 第一次进游戏，在首页粘贴 DeepSeek 的 API Key（https://platform.deepseek.com/api_keys 申请，充几块钱够玩很久），点「保存」。
   想要更准的查史，可以顺便填博查（Bocha）的 Key；不填就用免费的维基百科。
4. 在输入框里用一句话说你想当谁，比如：
      万历年间苏州的绣娘
      1068年的宋神宗
      明末辽东的边军
   或者直接点「随便来一局」。

【存档】
在 data\saves 里，关掉窗口会自动保存。Key 只存在本机 data\adapter-config.json，不会上传。
