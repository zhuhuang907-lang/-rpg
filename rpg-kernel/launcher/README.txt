历史模拟 RPG · 使用说明

━━━━━━━━ 最省事的装法（推荐）━━━━━━━━
1. 下载 HistoryRPG-Setup.exe（安装程序），双击。
   · 如果 Windows 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   · 如果杀毒软件（360、火绒等）拦截：选「允许」或「信任」。
2. 点「安装」，装完勾着「现在就开始玩」点「完成」。
3. 以后玩：双击桌面上的「历史模拟RPG」图标。

━━━━━━━━ 以后怎么更新 ━━━━━━━━
不用再去网页上下载。有新版本时，游戏页面顶上会出现黄色提示「有新版本了」，点「一键更新」：
自动下载（GitHub 慢就自动换国内加速地址）、核对文件没被改过、安装、把游戏重新打开。存档和 Key 不会丢。
也可以随时点右上角「检查更新」。

━━━━━━━━ 打开以后 ━━━━━━━━
· 会先出现一个小窗口「历史模拟 RPG」——游戏运行期间别关它；关掉它就是退出游戏。
· 浏览器会自动打开游戏页面。浏览器不小心关了，点小窗口上的「打开游戏」。
· 第一次玩：在页面上粘贴 DeepSeek 的 Key（https://platform.deepseek.com/api_keys 申请），点「保存」。
  博查 Key 可填可不填（https://open.bochaai.com 申请），不填就用免费的维基百科查史。
· 保存后会显示「✓ 连接成功」。如果显示连不上，点「检查网络」，它会告诉你卡在哪。
· 在输入框里用一句话说你想当谁，比如「万历年间苏州的绣娘」「1068年的宋神宗」，或者点「随便来一个」。

━━━━━━━━ 常见问题 ━━━━━━━━
· 页面顶上出现红色提示「这样打开用不了」：你是直接双击了游戏里的网页文件。请关掉它，双击桌面图标。
· 页面顶上出现红色提示「游戏服务没有在运行」：那个小窗口被关掉了。重新双击桌面图标。
· 连不上 DeepSeek，提示「证书校验失败」：杀毒软件的「HTTPS 扫描 / 网页防护」拦住了，把本游戏加入信任，或关掉这个功能。
· 提示「经过系统代理时被拒绝」：你开着代理/加速器，换个节点或关掉代理再试。

━━━━━━━━ 存档与 Key ━━━━━━━━
存档和 Key 都只存在你自己的电脑上（安装目录下的 app\data）。再装一次新版本，存档和 Key 都不会丢。
