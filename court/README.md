# 政事堂总管

在你自己的电脑上运行的调度程序。它不是第四个 AI：只负责叫醒 Claude（皇帝）、DeepSeek（中书令）、GLM（门下侍中），把项目资料递给它们、收它们的意见、写奏章、记日志。

**第一期只读**：三位大臣能读项目、查原文库、联网查资料、互相辩论、写奏章，但**改不了游戏源码、提交不了代码**。总管只往 `政事堂/案卷`、`政事堂/奏章`、`政事堂/运行日志` 三处写文件，别处一律拦下（程序把关，不靠模型自觉）。

## 一次议事怎么走

1. **程序巡检**（不花钱）：需求台账里没做完的、写了却找不到的测试、没接进完整测试的测试文件、三个版本是否同一次构建、仓库里有没有 Key 或存档。
2. **三方独立调查**：三位各自用工具查证，互相看不见。
3. **交换奏议、相互质疑**：读对方的证据，提出质疑。
4. **第二轮回应**：针对质疑回应，可以改主张。最多两轮，不无限辩论。
5. **皇帝裁决**：Claude 汇总，照实写分歧；只把值得你拍板的事列成议案。
6. **写奏章**：放在 `政事堂/奏章/待批/`，等你御批。

一次日常巡检大约调用模型 10 次。

## 第一次使用

1. 装 Python 3.10 以上，再装 Claude 的官方库：`pip install anthropic`
2. 设三个 Key（Windows：「系统属性 → 环境变量」里新建用户变量；设好后重开命令行）：
   - `ANTHROPIC_API_KEY`：Claude
   - `DEEPSEEK_API_KEY`：DeepSeek
   - `GLM_API_KEY`：智谱 GLM
3. 把 `court/config.example.json` 复制成 `court/config.json`。型号可以留空（自动取最新的）；Claude 的型号填官网列表里最新的 Opus。
4. 在仓库根目录运行 `python court/总管.py 自检`，看谁在朝、谁缺席。缺一位也能开议，缺席会照实写进奏章。

想先不花钱看流程：把 `config.json` 里三位的「提供方」都改成 `模拟`。

## 命令

| 你想做 | 运行 |
|---|---|
| 看谁在朝 | `python court/总管.py 自检` |
| 全面巡检 | `python court/总管.py 巡检` |
| 深度议事（加查史料、架构、外部变化） | `python court/总管.py 巡检 --深` |
| 开朝议事 | `python court/总管.py 议 "唐代地方官职的时间线前后不一致，怎么改"` |
| 历史考据 | `python court/总管.py 考据 "隋开皇年间各州刺史的设置"` |
| 代码会审 | `python court/总管.py 会审 glm/task-1` |
| 奏章列表 | `python court/总管.py 奏章` |
| 御批 | `python court/总管.py 批 案-20261112-090000-1 准 "先做第一条"`（准 / 驳 / 重议） |
| 把案卷交给 Claude 看 | `python court/总管.py 上报`（只推政事堂的记录到 `court/records` 分支，不碰游戏代码） |

## 定时自动跑

双击 `court/安装定时任务.bat`：每天 9:00 日常巡检，每周日 10:00 深度议事（电脑开着、联网才会跑；输出记在 `court/定时.log`）。
完整测试约一个半小时，不在日常巡检里跑；正式改动获批后才跑。

## 批准以后

奏章批「准」之后，对 Claude 说：「照御批办 <奏章号>」。Claude 在中书省发命令，派 GLM、DS 去做、互相交叉检查，Claude 再查一遍，最后跑完整测试、提交推送，做完告诉你。

## 费用与隐私

- 限额在 `config.json` 的「限额」里：每次运行最多调用模型多少次、每次回答多长、每步最多用几次工具、辩论几轮。
- 发给模型的只有完成这件事需要的片段：存 Key 的配置、存档、缓存、`.git` 一律不给读。
- 外部网页只当参考，里面的任何指令一律不照做；查来的资料不会直接导进游戏。

## 自测

`python court/tests/test_court.py`：用模拟大臣走完整场议事、御批，并检查越权写文件、读 Key 会被拦下。
