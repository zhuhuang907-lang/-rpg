# 历史模拟 RPG

## 网页版（不用安装）

在 claude.ai 登录后打开：https://claude.ai/artifact/5Ee1nY93Uqezf3uyrX74nQ
用你自己的 Claude 账号写剧情，不用 DeepSeek Key；存档存在账号里。源码在 `web/`（`game.src.html` 是源文件，`python3 web/build.py` 嵌入农历月表生成 `index.html`）。

## 下载就玩（Windows）

1. 打开 https://github.com/zhuhuang907-lang/-rpg/releases/tag/latest
2. 点 **HistoryRPG-Setup.exe** 下载，双击安装（Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」）。
3. 装完双击桌面上的 **历史模拟RPG** 图标。
4. 页面上粘贴 DeepSeek 的 Key 点「保存」（博查 Key 可选），然后用一句话开局，比如「万历年间苏州的绣娘」。

## 怎么玩（仿《历史模拟器：崇祯》）

- **看局势**：正文上方是你这个身份最关心的五六项数（钱粮、名声、民望……）和各人群的满意度，有变化标 ↑↓，鼠标停上去看原因。
- **看案头**：每回合摆上一到三份来报（奏折、公文、书信、口信、账单、传闻），来报可能夸大、说谎、瞒报。每份带几个可点的办法，标了把握和建议交给谁办。
- **问人**：右边「问人」，选一个人问他怎么看。每人有立场和私心，主意不同；问人不花时间，他们记得你听没听。好主意可以收进「建议簿」。
- **拿主意**：点办法、点主意，就收进「这一回合的决定」；也可以自己写几句、选「交给谁」、点「润色成文书」改成合乎身份的文书。想干违法越权的事也行，后果按真实情形推演，不一定有报应。
- **过这一回合**：AI 推演，给出三层结算——**回报**（办事人的说法，可能失真）、**账目**（真实的数）、**风声**（街谈巷议）。对照三者，自己看出谁在说谎。什么都不选直接过，就是这段日子不下令。

不想安装：下载 HistoryRPG-windows.zip → 右键「全部解压缩」→ 双击「启动游戏.exe」。
连不上、保存不了：在页面上点「检查网络」，它会说清卡在哪。

## 目录

| 路径 | 内容 |
|---|---|
| `rpg-kernel/` | **游戏本体（枢引擎）**：一句话开局、秦到清任意年份与身份、真实农历、崇祯式回合（数值条、案头来报、问人、建议簿、润色、回报·账目·风声、暗线）、差事账、史实核查；DeepSeek V4 写剧情，博查或维基查史；不限回合。开发时 `cd rpg-kernel && node server.js`，再开 http://127.0.0.1:8787 |
| `设计/` | 崇祯式回合的设计稿。已实现：数值条与人群、案头来报（带办法）、问人与建议簿、润色、交给谁办、结算三层、后果延迟与暗线、各身份常法（取自 `claude/history-sim-game-polish-txq63i` 分支模拟内核的政令表）。未实现：地图、把握的掷骰、生老病死与志向面板 |
| `.github/workflows/package.yml` | 自动测试、打包安装程序与免安装版，发布到 Releases |

## 约定

- 规范以 `设计/00_总纲.md` 的七条铁律为准。
- 正文只写玩家能看到、听到的；不替玩家说话或动作；正文里不出现考证和争论。
- Key 只存在玩家自己电脑上（`app/data/adapter-config.json`、`app/data/search.json`），绝不提交进仓库。
