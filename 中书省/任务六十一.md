## 怎么跑（在项目主人电脑上）

1. `git fetch origin && git checkout -B zcode/task-六十一 origin/claude/staging`
2. DeepSeek 的 Key 放进环境变量 `DEEPSEEK_API_KEY`（项目主人电脑上已有的那一个）。**绝不写进任何文件、不提交、不贴进聊天、不打印。**
3. 要 node、python3、playwright（含 chromium）、bash（Windows 用 Git Bash）。
4. 一张考卷一条命令（约一小时，开局十来分钟）：
   ```bash
   EXAM_ROOT=$HOME/rpg-exam bash web/tests/real/exam/exam.sh 1-皇帝-调兵与任免.txt
   ```
   跑完在 `$HOME/rpg-exam/<卷名>/` 下有：`play.log`（每回正文和回执）、`shots/`（每回局面页、舆图截图）、`st<回>.json`（账的要点）、`对账.txt`（程序自动对账）。**这些都不进仓库**（里面有玩家数据）。
5. 驱动跑满两小时会被停：从最后一回的存档接着跑——`curl -X POST --data-binary "$EXAM_DIR/lcr<回>.json" localhost:8798/load`，再把考卷剩下的行另存一个文件，用 `bash web/tests/real/exam/turns.sh 文件` 接着跑。

## 要报什么（每张考卷一份，`中书省/考卷回报/<卷名>-<日期>.md`）

先抄 `对账.txt` 全文。然后**你自己逐回读正文、看截图**，凡是下面这些，一条一行报上来：

1. **账和正文对不上**：正文说兵开到某地、几万人，账（局面页、军务页、舆图）上没有或数目不同；正文说任命了谁，人事树、人物页上没有；正文说花了钱，现钱没动。
2. **时间不对**：说过一个月，日子只走了一天或走了一年；季节、节气、年纪对不上；同一件事前后两回日子打架。
3. **人事不对**：死人出场、说话、办事；人的官职一回一个样；真人被改了名；王子、亲属被当成君主。
4. **军队不对**：兵瞬移、在路上就打仗、一支兵同时两处、没打仗兵数大减、到了地头账上还在半路。
5. **经济不对**：铺子、俸禄、税、利息跨月只算一个月或算重了；钱成负数；粮、田写成钱。
6. **界面不对**：一直挂着「正在推」超过三回；按钮点了没反应；出现 undefined、NaN、怪数。
7. **剧情离谱**：替主角说了玩家没说的话、改了玩家说的数目；心想事成；人物言行不合身份和年代。

每条照这个格式（**只写看到的事实，不猜原因，不提改法**）：

```
- 第N回｜类别｜正文怎么说（摘原句）｜账上/界面上是什么（截图文件名）｜为什么算错
```

一张卷跑完就提交推送一次：`git add 中书省/考卷回报/ && git commit -m "任务六十一：<卷名> 回报" && git push -u origin HEAD`。
只提交回报的 md，**不提交** play.log、截图、存档、st*.json。
