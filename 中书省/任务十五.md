## 要做什么（三个文件，只放数据）

1. `web/scenes/types.json` 戏型库，不少于八十种，各时段通用：
```json
{ "types": [ { "id": "", "name": "如 夜里来人、堂上对质、营中鼓噪、宴上试探、路遇、托孤、分家、催科、点兵、劝降",
    "fits": ["适合哪些事、哪些场合"], "beats": ["第一拍写什么", "第二拍", "第三拍", "停在哪"],
    "pitfalls": ["这种戏容易写坏的地方"], "model": "学哪部书哪一段的写法（只学节奏）" } ] }
```
2. `web/vocab/wudai.json` 时代用语表：称呼（上对下、下对上、平辈、自称，分军中、官府、乡里、宫里）、官名的俗称、钱粮布帛的单位、常见器物衣食、口头话、文书名目。每条带出处。
3. 同一文件里的 `absent`：**此时没有**的错词表，不少于两百条——后世才有的官名、称呼、物件、制度、说法（如这时没有的「师爷」「总兵」「巡抚」「银两当钱用」），每条写当时的说法。

## 验收
- `plan_metrics.py` 里戏型不少于八十、五代十国错词不少于两百。
- 先交错词表（里程碑二要用），再交用语表、戏型库。
