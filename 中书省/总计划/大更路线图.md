# 这次大更的路线图：从现在到发布（R-233）

> 项目主人（2026-11-14）：「把你的计划写到游戏这次大更结束，我希望玩的时候可以大幅度提升……保障游戏不仅好玩，玩法多样，而且不会有错误，趣味和多样性都有，还要有好玩的各项系统」。
> 这一页把 [总计划](README.md)（阶段与门槛）、[模型管束](模型管束.md)（七道闸）排成一条从头到发布的线。每个里程碑结束时项目主人手里都有一个能玩的预备版。**前一个里程碑项目主人没说行，不开下一个。**

## 这次大更叫什么、到哪算完

**版本 0.9.0「乱世」**。算完的标准只有一条：项目主人在五个时段（五代十国、汉末三国、两晋十六国、南北朝、唐末）里随便开一局、随便玩，说「行，发布」。

## 玩家会感到的六样提升（每样对着后面的里程碑）

| 提升 | 现在 | 大更以后 |
|---|---|---|
| 人是对的 | 一国一年只有十几位真人，其余临场编 | 朝堂照史书排满，补的人标明、记死；身边人各有来历 |
| 字是对的 | 写错的人和事会存进存档、越滚越多 | 错的进不了存档；到眼前的错每百回不超过两处 |
| 世界合时代 | 三国到南北朝一套规矩，隋唐五代一套 | 每个时段、每类政权有自己的活法、称呼、台阶、祸事 |
| 做什么都行 | 身份分得死，换身份账接不上 | 没有固定身份，随时改行，兵钱人仇家名声带着走 |
| 回回不重样 | 事靠模型临场想，容易重复、平淡 | 一个时段三百件以上的世事、八十种以上的戏型，程序挑 |
| 系统有嚼头 | 一百三十个系统，各算各的 | 十二个主干系统，每个有取舍、会输、和别的咬着 |

## 里程碑一　五代十国·人对了（底子）

- 做什么：二十一个政权朝廷数据（任务六）、列传逐卷摘履历与关系（任务十）、世情库（任务九）、任职表过关（任务八）、模型调用清单（任务十一）。
- 过关：总计划阶段一的门槛全过。
- 项目主人拿到：预备版里开 930 年后唐、荆南、南唐，朝堂是满的、人是对的。

## 里程碑二　五代十国·字对了（管住模型）

- 做什么：先定后写（任务十六）；点名权、分拍、双稿、兜底（任务十七）；时代用语表与错词表（任务十五的一部分）；对表程序（任务十三）。
- 过关：真模型连玩两百回（八套打法各二十五回），模型管束第七道的五条线全过；专门的测试——往正文里塞一个假官、一个假死讯，存档里一样没有。
- 项目主人拿到：同样的局，写出来的人、官、年号不再错；偶尔有一回文字平淡（兜底戏），但没有错的。

## 里程碑三　五代十国·好玩了（玩法）

- 做什么：
  - 游戏读世情库、不设固定身份、随时改行（任务十二）。
  - 世事库三百件、戏型库八十种（任务十四、十五）接进游戏。
  - 朝局与军镇由程序按月转（总计划戊一）。
  - 文戏：在场的人各有所求所惧旧账，前后一致（总计划丁一）。
  - **十二个主干系统逐个过「好玩四问」（任务十八）**，见下节。
- 过关：总计划阶段二的门槛；每个主干系统的四问都有测试看着；项目主人自己随便玩，说行。
- 项目主人拿到：这是提升最大的一版。可以从农家子玩到节度使，中间随便拐弯。

## 里程碑四　铺到另外四段

- 顺序：汉末三国 → 两晋十六国 → 南北朝 → 唐末。每段照同一套：政权与朝廷数据 → 列传履历与关系 → 世情库八十条 → 世事库三百件（戏型库通用的沿用，各段另补二十种）→ 时代用语与错词表 → 真模型一百回过线。
- 注意：十六国、南北朝的任职表现在四成是错的（任务八之二），这两段的人一律回原文核，过了百分之五的线才进游戏。
- 过关：每段各过里程碑一、二的线；项目主人每段开一局说行。
- 项目主人拿到：每做完一段，预备版里多一段能玩。

## 里程碑五　收官与发布（任务十九）

- 模型调用点降到四十以下；同一步重跑三次账一致。
- 大文件拆开，三个版本和拆前逐字一致。
- 旧存档打开不坏（照旧办法兼容，旧局不强行套新库）。
- 每回用时和花费量出来写进汇报：一回从玩家出手到正文出完不超过现在的用时；分拍和双稿多花的调用，用砍掉的那些调用抵回来。
- 冻结的旧系统逐个定去留，列单子请项目主人过目。
- 预备分支跑完整测试全过 → 给项目主人发试玩链接和这一版的说明 → **项目主人说「发布」才推发布分支** → 桌面版打包成功、网页版和 claude.ai 版同步 → 汇报。

## 十二个主干系统与「好玩四问」

系统不是太少，是太多太薄。这次不再加新系统，把现有的一百三十个并成十二个主干，其余并进去或冻结。

| # | 主干系统 | 管什么 |
|---|---|---|
| 1 | 人情与旧账 | 好感的来由、恩与怨、请托与回报、翻脸 |
| 2 | 谋划 | 结交、离间、构陷、举荐、行刺、策反：有步骤、有进度、会败露 |
| 3 | 随从与伙伴 | 跟着你的人：本事、脾气、心愿、忠心，会走会反 |
| 4 | 家业与营生 | 田、铺、船、庄客、月账、借贷、被盘剥 |
| 5 | 仕途与军功 | 这个时代往上走的各条路和台阶（照世情库） |
| 6 | 阵前 | 你自己在仗里的位置和抉择；大仗胜负由程序算，落到你头上是一场戏 |
| 7 | 朝局与党争 | 席位、派系、清议、君心，按月转 |
| 8 | 地盘与军镇 | 据地、养兵、粮道、叛服、称号 |
| 9 | 世事与奇遇 | 世事库：天灾、兵祸、机缘、怪事，什么都可能发生 |
| 10 | 名声 | 官声、军望、乡评、恶名，各管各的门路 |
| 11 | 家族与承继 | 婚姻、子嗣、分家、立嗣；主角死了可以接着玩他的后人 |
| 12 | 身家性命 | 年岁、病、伤、刑狱、流放、逃亡 |

每个系统都要答得上这四问，答不上就不算做完：

1. **看得见吗**：这个系统现在的状况，玩家在页面上一眼看得到几个明白的数或几句明白的话。
2. **有取舍吗**：在这个系统里做一件事，一定要花掉或得罪点什么；没有只赚不赔的按钮。
3. **会输吗**：有真实的坏下场，而且真会发生，程序不暗中救场。
4. **咬着别的吗**：它的结果至少改变另外两个主干系统的局面（例如欠饷 → 随从忠心降 → 兵变 → 名声与地盘都变）。

舆图、行旅、见闻、档案馆是工具页，不算主干，照旧留着。
