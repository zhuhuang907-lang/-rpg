## 要做什么

玩家原话：「你不知道明朝是卫所制吗，你这做的什么垃圾，怎么才这么几个兵」。

现在皇帝、一方之主开局的兵马是模型凭印象列的，常常只列几支、数目偏小。改成**程序照兵制表给**，模型只填人名。你做这张表。

新文件 `web/history/milsys.json`，数组，每条是一个朝代的一个时段（兵制变了就分段）：

```
{ "dyn": "明", "from": 1368, "to": 1449, "sys": "卫所制",
  "total": { "nominal": 数, "actual": 数, "src": "出处" },
  "units": [ { "name": "京营·五军营", "kind": "京营", "at": "北京", "nominal": 数, "actual": 数, "head": "统兵官的官名（不是人名）", "src": "出处" }, ... ] }
```

- 覆盖：秦、西汉、东汉、三国（魏蜀吴）、西晋、东晋、南北朝各朝、隋、唐（府兵、天宝边镇、唐后期藩镇）、五代各朝及十国、北宋、南宋、辽、金、西夏、元、明（洪武、永乐、正统土木后、嘉靖、万历、崇祯）、清（顺治到乾隆、嘉道、咸同、光宣）。
- 每段 `units` 照当时的编制写到「大军区」一级：明朝写京营三大营、上直亲军、九边每镇、各都司（合计）；宋写三衙禁军、各路屯驻、厢军；清写京师八旗、各省驻防、各省绿营；唐写十六卫、各边镇节度。每段十到三十条。
- 数目：史书有载照载（写书名、卷）；没载照编制推（写「照几卫几所推」），**不写整数凑数**。名义（额）和实在分开写。
- 不写人名（人名由游戏照任职表配），只写统兵官的官名。
