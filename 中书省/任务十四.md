- 承办：zcode　审查：Claude

## 要做什么
新建 `web/events/wudai.json`，只放数据。把五代十国七十年里一个人可能碰上的事尽量写全：天灾、兵祸、官司、机缘、婚丧、买卖、军中、官场、宫里、路上、寺观、部落、怪事。不少于三百件，没有上限。

```json
{ "period": "wudai", "range": [907, 979],
  "events": [
    { "id": "不重复的短名",
      "kind": "大类，自己定",
      "title": "一句话：出了什么事",
      "when": { "who": ["沾着世情库哪些活法的人会碰上，空着就是谁都可能"], "where": "地方或政权类别，可空",
                "season": "季节或月份，可空", "need": ["要先有的情形，用白话写，如 欠饷三月、城被围、家有未嫁女"] },
      "weight": "常见|偶有|罕见",
      "paths": [ { "name": "一种走向", "cost": "要花掉或得罪什么", "effect": ["程序落账的结果，一条一句白话：钱粮、人、关系、名声、伤病、官职、兵"], "next": "可接的下一件事的 id，可空" } ],
      "cast": ["这件事里要出场的是什么人（用世情库里的名目，不写具体人名）"],
      "src": "这类事的出处：书·卷，本传里的实例最好" } ] }
```

## 规矩
1. 每件至少两种走向，每种走向都有代价；至少一种是坏下场。不写只赚不赔的事。
2. 不写具体真人名（真人由游戏照表填进去）；不写数字示例；不写「必须」「只能」。
3. 要是这个时代真会有的事，带出处。怪事、奇遇照当时人信的写（谶语、天象、梦、佛道灵异），不写后世才有的东西。
4. 往多里写、往不同里写：同一类事换了人、换了地方、换了年景就是另一件。

- 回奏贴十件抽样：事 → 出处 → 原文片段。
