### P1-1 时间 400 天地板：玩家说“过一个月”，账房报大数就跳 400 天

**代码**：`web/game.src.html:15707`

```js
let days = Math.max(0, Math.min(capDays, Math.max(400, Math.round(spanMonths(d.span, said) * 30.5)), 1900, Math.round(Number(d.elapsedDays) || 0)));
```

`Math.max(400, …)` 是地板：只要账房报的 `elapsedDays ≥ 400`，玩家要求的“一个月”（30.5 天）会被抬到 400 天。李从荣线第 111 回“过一个月跳一年多”就是这条。

**实测**（`probe2.js`）：

```
spanMonths('过一个月') = 1
按上式 elapsedDays=400 → days = 400     （应为 30）
```

同一行还有“此后半年”不认的老毛病：`spanMonths('此后半年，按月照章办事') = 0`（“此后/自后/今后 N 月年”不在正则里），玩家说此后半年，钟最多走 45 天。

**建议**：删 400 地板，改成 `min(capDays, max(span 换算, elapsedDays))`；`SPAN_RE` 加“此后/自后/今后 N 月年”。我在 `work/rpg-fixes` 已改好并验证（`patches/1-时间与写戏体检.patch`），**尚未合入主干**。

### P1-2 写戏体检缺三条：改稿标记、同景重写、复读/对话占比

**实测**（`probe2.js`，直接调主干函数）：

```
draftFaults('你躬身（删去，仅躬身）退下。', …) → 没有“改稿标记”告警（mark_flag=false）
```

### P2-1 存档先删旧再写新，两处都失败就丢档

`web/game.src.html:951`：

```js
try { localStorage.setItem('hrpg:save:'+id, J); local = true; }
catch (_) { local = false; try { localStorage.removeItem('hrpg:save:'+id); } catch (_) {} }
```

### P1-10 物价极端值没有口径/封顶

- 南北朝 35 格、唐末 16 格米价 ≥ 5 万文；峰值 **2,157,060 文**（540—549 江淮，源《魏书·食货志》私铸薄钱）
- `econUnitFix` 只处理单位是“贯/两/缗”的情况（`/^(贯|两|缗)$/`），单位“文”不折算
- 游戏买粮 `cost = E.rice * n`，一石 200 万文 → 玩家永远买不起，经济直接失真
- 这些数字历史上是“斗”价/极端通胀，口径没统一到“石”
- 建议：统一斗→石换算、给常态价设上限（如 100 倍常价），或在 `basis` 标明“非常年份，只作背景”
