# 外部策划评审：逐条对照与取舍（R-245，2026-11-17）

项目主人的话：「帮我按照这个方面，提升游戏，考虑 ai 性能能做到那些，不需要强人所难」。
原则：程序算得出来的由程序做（不花钱、不出错）；要模型做的只挑它做得稳的；做不稳的写明不做。

| 评审的意见 | 游戏里现在 | 取舍 |
|---|---|---|
| 核心循环要有「产生新的关系与问题」「看见人生变化」 | 有「眼下的事」「临门的事」；人生变化散在年谱里，看不出走了多远 | **这次做**：人生纪事（程序自动记转折，成败都记） |
| 人生志向 | 有（志向系统，一次立一个，程序量进度） | 已有；往后把志向摆到开局和「眼下」里更显眼 |
| 人生里程碑、人物传记 | 没有 | **这次做**里程碑；传记往后做（一局结束时请模型照纪事写一篇，一次调用） |
| 死亡不是结束：继承人、身边人、重开；不全盘继承；被俘流放罢官也能接着玩 | 只有「模型说主角死了且有继承人」才换人，没得挑 | **下一批做**：程序认死亡与退场，摆出可接着玩的人，照继承法分家产、人情打折、仇家和债留着 |
| 系统分三层，面板随身份展开，不让商人看人事树 | 页签照身份开一部分（朝局、军务、势力），其余十来个一直摆着 | **下一批做**：常用的摆出来，其余收进「更多」，用到了再展开 |
| 前三十分钟：先过日子，系统随剧情出现 | 开局有处境交代和一场戏；面板一次全给 | 同上一条一起做 |
| 历史机会窗口、玩家介入程度 | 有大势主线、史事同步、对历史的影响累计；没有「介入程度」这个明面的说法 | 往后做：照现有的影响账给每件大事标「风闻、接触、介入、改变」 |
| AI 四层架构：状态层、裁定层、导演层、执行校验层 | 状态和裁定在程序；有场景简报和人物底（接近导演单）；校验有程序体检加模型审稿 | 方向一致，不另起炉灶。**不做**单独再加一次「导演」模型调用（多花一次钱、多等十几秒）；导演单由程序从裁定和世事库拼 |
| 事实校验和文笔审稿分开 | 事实多半已由程序查（名单、错词、凭据、对账）；审稿模型两样都看 | 往后做：审稿只留文笔和情理 |
| 事件模板加 AI 自由叙事（军中欠饷那种） | 有世事库（每段三百件，带走向和后果）、临门的事 | 已有底子；往后把世事的几条走向做成可点的选项，也照旧可以自己打字 |
| 叙事记忆和世界记忆分开：承诺、恩怨、秘密结构化 | 有定本（文字）、人物好感变化的来由记录、幕后真相 | 往后做：要紧的人各存「恩、怨、诺、密」几条，程序能记的先记（送礼、弹劾、投门下、救过、害过） |
| 统治者「朝廷今日」，政务有人出面 | 有时政、朝议、国计面板；偏表格 | 往后做：把今日最要紧的几件事排成一张卡，每件有人来奏 |
| 政治决策三种成本、非正式权力（实际影响力） | 政令有阻力、派系表态、折扣；没有「实际影响力」 | 往后做：朝局态势里给要紧的人加「说话管不管用」 |
| 骑砍：伙伴有自己的人生、路上小遭遇 | 有头领心愿、路上遇事 | 已有第一版，不再加 |
| 钢四：战前计划、战争预期、败后追责落到人 | 有战线、补给、作战；败后追责没有 | 往后做败后追责（程序触发，接朝局的被参） |
| CK3：秘密、NPC 之间的关系网、派系、互动理由 | 有派系、朝臣互谋、好感来由；互动只回成不成 | 往后做：走动不成时说明缘由（他为什么不见你） |
| 真实与好玩：知情范围、给因果不只给结果 | 国丧宴乐、越权等已改成「做了，后果照账走」 | 往后做：把「谁看见了、谁拿它当把柄」记成明账 |
| 等待四十到六十秒要有信息价值 | 现在等的时候什么都不摆 | **下一批做**：摆已经确定的东西（此时此地、朝局近事、眼下的事），不泄露这一回 |
| 动态上下文检索，少发材料 | 另一场对话在做（裁材料、程序自己记账、模型按需查账） | 在做 |
| 回合分三种规格（小事短写、大事长写） | 有「家常的一步」，篇幅没有明显变短 | **下一批做**：小事一两百字 |
| 重玩价值：同年代不同位置、人物传记 | 任意年代任意身份已有；传记没有 | 传记往后做 |
| 文字沉浸：地点感、人物声音、关系网图、时间感、音效 | 写戏规矩里有地点和口吻；没有关系网图；没有声音 | 关系网图往后做；**音效不做**（纯文字游戏先把字做好） |
| 做真实玩家测试，不只自动测试 | 真模型连玩有脚本；项目主人亲手验的很少 | 照做：每批做完给项目主人一个固定的试玩剧本 |
| 测试剧本：从军户到节度使 | 没有 | 往后拿它做整体验收的打法（真模型连玩） |

## AI 做不到、不强求的
- 给朝中几百个人各配一套由模型推的长期计划：太贵，也推不稳。只给要紧的十来个人用程序规则转（已做第一版：朝局里的人自己动）。
- 让模型自己保证不写错：靠不住。照旧由程序在它前后把关（名单、凭据、对账、错词）。
- 一回里多请几次模型来「导演」「分别审事实和文笔」：每多一次多一毛钱、多等十几秒，不做。
