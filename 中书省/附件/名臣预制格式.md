# 名臣预制包格式（R-244，2026-11-16 宰相定）

项目主人定：**重要的真人提前做好**（打「名臣」等标签，按出没地点判断主角够不够得着）；**次要人物可以虚构**（由游戏现场生成，不进预制包）；玩的时候缺什么再用博查补充搜索。

## 文件
`web/figures/<段名>.json`，段名：`wudai`（907—979）、`tangmo`（712—906）、`sanguo`（168—280）、`jin16`（280—439）、`nanbei`（439—581）。一段一个文件。

```
{
  "era": "段名", "range": [起年, 止年], "source": "所据书目，逗号分开",
  "people": [ 人物, ... ]
}
```

## 一个人物
| 字段 | 必填 | 写什么 |
|---|---|---|
| name | 是 | 史书通行的全名（不写字号、不写「某」） |
| tag | 是 | 一个，从这几样里挑：名臣、名将、君主、后妃、宗室、宦官、藩帅、文士、僧道、豪强、外族首领 |
| tier | 是 | 1 = 天下闻名（宰相、节度使、开国功臣、名将）；2 = 一方要人（刺史、侍郎、大将）；3 = 有传有名但不显 |
| born / died | 是 | 公元年；史书没有的写 null（不编） |
| clan / native | 否 | 姓氏郡望、籍贯（当时地名） |
| posts | 是 | 任职：`{"polity","office","from","to","place","how","src"}`；office 写当时全称；place 写治所或任职地；how 写「明载」或「推定」（推定要在 src 里说依据） |
| where | 是 | **出没地点年表**：`{"from","to","place","why","src"}`——这几年人在哪里（任职地、京城、隐居地、流放地、军中）。年份要连上，posts 没覆盖的年份也要写（在家守丧、闲居、被囚都算） |
| stats | 是 | `{"理政","统兵","理财","忠诚","操守"}`，每项 0—100 的整数，**另给 statsWhy**：每项一句史书评语或事迹（带书名卷次）。拿不准的项写 null，不凑数 |
| traits | 否 | 至多三个，只从这些里挑：勇武、怯懦、贪财、廉洁、野心、安分、多疑、宽厚、刻薄、好名、忠直、圆滑、仁厚、残忍、好色、勤勉、懒散、骄横、谦退；每个要在 statsWhy 或 brief 里有依据 |
| ties | 否 | `{"name","rel","src"}`：父子、兄弟、婚姻、养父子、门生、举主、仇人、同党 |
| faction | 否 | 所属派系或集团（如「河东集团」「牛党」），没有不写 |
| fate | 是 | 结局一句（怎么死的、谥号） |
| brief | 是 | 生平三句以内：做过什么、为人、在本段要紧在哪 |
| src | 是 | 主要出处：书名·卷次·篇名 |

## 规矩
1. **只收真人**；次要人物不用做（游戏会虚构）。每段至少收：本段全部君主、宰相（同平章事、尚书令、丞相等）、节度使/刺史中有传的、名将、有传的文士。数量见各任务单。
2. 年份、官职、关系一律照原文库 `corpus/` 能核的先核；核不到的写 how「推定」并说依据；**不编生卒、不编任职**。
3. 跑 `node web/tests/hist_audit.js` 必须 0 处可疑（人死后不任职、各表卒年一致、同一君主各表在位年一致）。同一个人在 `web/court/`、`web/tenure/`、`web/history/` 里已有的卒年、任职，预制包要和它一致；发现旧表错了，在回奏里写出来，不自己改旧表。
4. 不写这一年代还没有的官名、地名（查 `web/vocab/<段>.json` 错词表）。
5. 格式里不许照抄示例数；每个数都要有出处。
6. 分批交：每批五十人左右一个提交，回奏写清本批收了谁、抽样十条（人→出处→原文片段）。
