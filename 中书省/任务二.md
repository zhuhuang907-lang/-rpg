## 做法提示

- **每条都要从原文库核**，不凭记忆。原文库在仓库的 `corpus/`，本机这样查：
  ```bash
  cd rpg-kernel && node -e "require('./core/histlib').search('高颎 尚书左仆射',['suishu'],4).then(r=>console.log(JSON.stringify(r,null,1)))"
  ```
  这一段用：`weishu`（魏书）、`beiqishu`（北齐书）、`zhoushu`（周书）、`beishi`（北史）、`songshu`（宋书）、`nanqishu`（南齐书）、`liangshu`（梁书）、`chenshu`（陈书）、`nanshi`（南史）、`zizhitongjian`（资治通鉴）、`tongdian`（通典）。
- 月份：史书只记到季或年的，`m` 写 0（程序按季末、年末排，R-159）；不要硬填。
- 干支日 `gz` 有把握才填；没把握宁可不填该条的 `d`、`gz`。
- 北魏分裂（534 东魏、535 西魏）、齐代东魏（550）、周代西魏（557）、陈代梁（557）、侯景之乱（548–552）、西梁（555 起）都要分清起止年月。
- 真人的 `posts` 用当时的官名全称（「尚书左仆射」，不写「宰相」了事；宰相身份可在括号里注）。
- 拿不准的人或事**不收**，在回奏里列出来交给审查者和 Claude 判断。
