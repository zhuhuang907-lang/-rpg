# 任务四十二（zcode·档乙）五段开局底账预制：户口、物价、政区四邻

- 承办：zcode 档乙
- 审查：Claude
- 对应需求：R-244（开局花费大头：真模型实测 930 年洛阳开局 1.21 元，其中人口推算 5 次、地理 12 次、物价 2 次、方志 6 次——每开一局都重推一遍，同年同地答案应当一样）
- 分支：`zcode/task-42`
- 优先：排在档乙名臣预制（三十八至四十）之后、旧活之前

## 要做什么
新建 `web/preset/<段名>.json`（wudai、tangmo、sanguo、jin16、nanbei 各一个），格式：
```
{"era","range","source",
 "prices":[{"from","to","region","unit","rice","wage","landPrice","yield","rentRate","cloth","src","basis"}],
 "pop":[{"year","place","households","mouths","src"}],
 "places":[{"name","level","seat","from","to","neighbors":[],"terrain","src"}]}
```
1. **prices**：每段按十年、按大区（关中、河南、河北、河东、江淮、江南、巴蜀、荆湖、岭南）给米价（一石）、短工日钱、中田亩价、亩产、租率、绢价。**unit 一律写「文」**，数照史料（食货志、通典、册府元龟、通鉴所记米价、绢价、和籴价）；查不到的那格写 null，不推。basis 写依据原文一句。
2. **pop**：照各史地理志、元和郡县图志、太平寰宇记、通典的户口数，记州郡户数、口数和所据年份；没有的州不写。
3. **places**：本段主要州郡（至少都城和任务四十一那三十个大州郡），写级别（州、郡、府、镇）、治所、存续年份、四邻州郡、地形一句。
4. 游戏开局照这个直接排物价、人口、地理，不再请 AI 推（读包的程序宰相写）。

## 验收
- 抽二十格对原文；unit 全是「文」；没有出处的数一个都不许有。
- 同一州郡在 places 里的存续年份和 `web/history/` 里的政区、政权总表不矛盾。

## 规矩
- 出处写书名卷次篇名；核不到写 null；不写「某、不详、待查」。
- 先 `git fetch origin && git merge origin/claude/staging`；分批提交推送；推之前跑 `python3 web/build.py`、`node web/tests/prompt_guard.js`、`node web/tests/hist_audit.js`（0 处可疑）。
- 不碰 `web/game.src.html`。有问题写 `中书省/问答/zcode.md`，照自己的理解接着做。
