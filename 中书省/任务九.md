## 要做什么

玩家原话：「我这是 rpg，做什么都可以，根本就没有固定的身份啊，可以随时切换」「身份可不止 9 个，有相当多，而且不同时代还不一样，你可以交给 zcode，写的超多」「灵活性很大，什么事情都可以发生，不要拘泥于一些事情」。

新建 `web/roles/wudai.json`（907–979），只放数据，不改游戏。把五代十国这七十年里**人有哪些活法**尽量写全：不少于八十条，没有上限，史书里见得到的都收。

```json
{ "period": "wudai", "range": [907, 979],
  "ways": [
    { "name": "这种人当时怎么叫（用当时的名目）",
      "kind": "大类，自己定，如 军中、官府、幕府、宫廷、宗室、士人、僧道、工商、乡里、江湖、部落、贱籍、流离",
      "applies": "哪些政权或地方有（如 中原五朝、南方诸国、契丹、沿海、河东）",
      "what": "一两句：这是什么人、在世上什么位置",
      "become":  [ { "how": "常见的一种成为法", "src": "书·卷" } ],
      "doing":   [ { "what": "平日做什么、归谁管、靠什么吃饭", "src": "书·卷" } ],
      "happens": [ "可能碰上的事，一条一句，不少于八条，越多越好：好事、坏事、怪事、转机都要" ],
      "leads":   [ { "to": "常往哪去（另一种活法的 name，或一句话）", "by": "凭什么", "src": "书·卷，本传里的实例最好" } ],
      "names":   { "self": "自称", "byUp": "上头怎么叫", "byDown": "下头怎么叫" },
      "absent":  [ { "what": "容易写错的、这时代没有的东西", "instead": "当时的说法或替代" } ],
      "src": "这一条总的出处" } ] }
```

## 规矩（最要紧的三条）

1. **这是材料，不是清单**。`become`、`leads` 写的是「常见的」，不是「只能这样」。不要写「必须先……才能……」「不可以……」这类话；玩家做库里没写的事，游戏照样让他做。
2. **往多里写、往细里分**。同是当兵：牙兵、厅子都、银枪效节、义儿军、镇兵、乡兵、水军、蕃汉杂兵，各是一条；同是做官：枢密院的、三司的、馆阁的、州县的、幕府的（掌书记、判官、推官、孔目官、押牙、客将），各是一条。不同政权不一样的分开写（契丹的、南唐的、吴越的、蜀的）。
3. **每条有出处**。`become`、`doing`、`leads` 每一小条都要书名卷数（旧五代史、新五代史、通鉴、五代会要、册府元龟、通典、文献通考，本传里的实例最好）；`happens` 可以不逐条注，但要是这个时代真会有的事。核不到的不编，写进回奏。
