## 自动政事堂（政事堂总管）

玩家电脑上的 `court/` 程序会定时把三方叫来议事（直接调三家的接口，不经 zcode、opencode），记录放在：
- `政事堂/案卷/<案号>/`：案情、三方独立调查、质疑、回应、裁决，一步一份；
- `政事堂/奏章/待批/`：等玩家御批的奏章（批了移到 `已准/`、`已驳/`、`重议/`）；
- `政事堂/运行日志/`：每次运行一行。
制度见 `政事堂/章程.md`（第十二章），用法见 `court/README.md`。下面是不经总管、由 GLM、DS 在仓库里写意见的办法。

## GLM、DS 怎么写意见

1. 读 `政事堂/议题X/议题.md`。需要时读代码、查原文库，拿事实说话。
2. 从 `claude/gallant-davinci-l8pni0` 拉分支 `glm/yiti-X` 或 `ds/yiti-X`。
3. 新建 `政事堂/议题X/GLM.md` 或 `政事堂/议题X/DS.md`，照下面格式写，提交、推送这个分支。
4. 只写自己那一份；不改议题、不改对方的意见、不写裁决。

```markdown
# 议题X · GLM（或 DS）意见
- 主张：一句话
- 理由：一条一条，能给证据的给证据（文件、搜索关键词、原文库出处、测试结果）
- 代价与风险：这样做要花多少工、可能坏什么
- 若不采纳我的主张，退而求其次：……
- 我愿意承办的部分：……
```

意见要独立写，**不要先看对方的意见再写**（远端有对方的分支也先别看）。

## Claude 怎么裁决

两份意见到齐（或等了一轮还缺一份）就裁：新建 `政事堂/议题X/裁决.md`，写采纳什么、驳回什么、为什么，以及据此发出的命令（任务几、派给谁）。
