# 开场提示词

平时不用写提示词：对 zcode（GLM）或 opencode（DS）说一句——

```
扫描仓库 zhuhuang907-lang/-rpg（分支 claude/gallant-davinci-l8pni0），照 AGENTS.md 办。
```

它会自己认身份、去中书省找命令、去政事堂找议题，办完一件再找下一件，没有了会告诉你「暂无差事」。

## 它没有自动读 AGENTS.md 时

整段发给它：

```
你是这个项目的开发者之一。先读仓库根目录的 AGENTS.md，照里面的「第一步认身份、第二步自己找活、第三步怎么办一件命令」去做。
你在 zcode 里就是 GLM，在 opencode 里就是 DS。只推你自己前缀的分支（glm/ 或 ds/），不推 claude/gallant-davinci-l8pni0，不开 PR。
开工前先用三五句话说你找到了哪件差事、打算怎么办。
```

## 它不能读仓库时（普通聊天窗口）

把 `AGENTS.md`、它的命令文件（`中书省/任务X.md`）、命令点名的技能卡贴给它，再发：

```
以上是规程和你的命令。照命令「要做什么」完成，输出完整的新文件内容，并照命令末尾「回奏」的格式写回奏。拿不准的史实不要编，列出来。
```

拿到输出后交给 Claude 落进仓库、跑测试。
