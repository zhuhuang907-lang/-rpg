# 外部文库：cn-history-220-979（公元 220—979 中古史全文库）

> 2026-11-17 项目主人让 opencode 上传：<https://github.com/zhuhuang907-lang/cn-history-220-979>
> 用途：给名臣预制、世事库、制度库、长官表、宰辅表核原文与卷次；本库**不进本仓库**（76 MB 正文），用时现拉。

## 有什么

- 全文 50 部、2,504 卷、约 2,523 万字：三国、两晋、南北朝、隋、唐、五代十国、宋初统一段的正史、编年、政书、笔记、类书（含北魏书、北齐书、南史、北史全本，补本仓库 `corpus/` 的缺卷）。
- 结构化游戏数据：96 政权、159 人物、155 事件、87 地点、90 术语、22 组同名辨析（`data/`，1.7 MB）。
- 本地 SQLite 全文索引 + CLI 检索：繁简通检、按书/时代/可信度过滤。
- 书目与可信度分级：`A` 正史/编年、`B` 政书/类书、`C` 笔记、`F` 小说演义（**不得当史实**）、`M` 现代研究（只有书目，无正文）。

## 怎么用

```bash
python scripts/fetch_history_corpus.py            # 默认拉到仓库的同级目录 ../cn-history-220-979
python ../cn-history-220-979/scripts/build_index.py   # 建索引，约 3 分钟、300 MB（不进 git）
python ../cn-history-220-979/scripts/search.py 玄武门
python ../cn-history-220-979/scripts/search.py 同中书门下三品 --period 唐前期 --reliability A
```

正文也可以直接读：`texts/<书>/卷NNN.txt`（如 `texts/beiqishu/卷017.txt`）。

## 引用规矩（照本库 NOTICE）

1. 古籍原文属公有领域，可自由引用、复制、改写；**引用必须写书名、卷次**（如「北齐书·卷十七·斛律光传」）。
2. Wikisource 转录的标点、校勘按 **CC BY-SA 4.0**，转载时保留出处。
3. `F` 级（演义、小说）只能用作叙事氛围，不得进需求台账、史料包、名臣预制等史实字段。
4. `M` 级只有书目，正文不引。
5. 查不到就写「核不到」，不编卷次、不编生卒。
