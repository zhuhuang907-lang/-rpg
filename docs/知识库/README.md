# 知识库索引

本项目用「项目专用知识文档 + 技能卡」来协作开发：Claude 研究并整理规范，DeepSeek 和 GLM 照规范写代码、交叉审查、测试。
这些文件只是本 RPG 软件的开发参考与任务指令，不用于任何模型训练。

## 先读哪几篇

| 你要做 | 读 |
|---|---|
| 任何活（第一次来） | `AGENTS.md` → 本页 → `架构.md` → `协作流程.md` |
| 写代码 | `架构.md`、`接口与数据规范.md`、`测试标准.md`、命令点名的技能卡 |
| 审别人的改动 | `skills/交叉审查/SKILL.md`、`测试标准.md` |
| 改提示词、正文规矩 | `skills/改提示词与护栏/SKILL.md`、`设计/05_GM提示词.md` |
| 动史料、真人、官职 | `skills/史实数据与真人/SKILL.md`、`接口与数据规范.md` 第五节 |

## 文档清单

| 文件 | 内容 |
|---|---|
| `架构.md` | 一份源码三个版本、源码分区地图、一回合怎么走、游戏里的 AI 分工、存档、桌面版 |
| `接口与数据规范.md` | 程序定数 AI 填格、给 AI 的材料、AI 调用、存档、史料文件字段、文案 |
| `测试标准.md` | 三层测试、写界面测试的模板、什么改动配什么测试、交测试结果的格式 |
| `协作流程.md` | 三方与机构（中书省、政事堂）、一件命令的路、定方向、分支与提交、台账条目格式 |
| `开场提示词.md` | 玩家转发给 DeepSeek / GLM 的开场话 |

## 技能卡（`skills/`）

| 技能卡 | 什么时候用 |
|---|---|
| `修bug先复现` | 修任何 bug |
| `加按钮与真点测试` | 新增或改按钮、面板 |
| `改提示词与护栏` | 改写正文的规矩、给 AI 的格式 |
| `史实数据与真人` | 动史料、真人、官职、年岁、地名 |
| `新需求入台账` | 玩家提新要求 |
| `交叉审查` | 审另一个模型的改动 |
| `构建与提交` | 构建三个版本、跑测试、提交 |
| `写汇报` | 给玩家写结果 |
