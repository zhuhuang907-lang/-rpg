# 加按钮与真点测试

## 步骤

1. 找到对应的界面分区（`========== 画面` 及各系统自己的渲染函数），照现有按钮的写法加。
2. 按钮的内部标记（data 属性、动作名）**全局唯一**，先 `grep` 确认没人用过。
3. 点了要有**真实后果**：落到存档、账目、行动单上，而不是只弹一句话（玩家原话：「很多按钮可以随便按、没有真实的后果」）。
4. 前置条件不满足时：按钮说清缺什么，或当场去补（R-144），不能点了没反应。
5. 照身份显示：这个身份够不着的按钮不出现（例如百姓看不到朝局，R-136）。
6. 写测试：`web/tests/qa/` 里用 Playwright **真点**它（`await p.click(...)`），再查存档字段和页面文字。只调函数不算。
7. 接进 `web/tests/qa.sh`。按钮清点类测试（`allbtn.js`、`btnaudit.js`、`clickall.js`）若有名单，一并更新。

## 检查

- [ ] 测试里真点了这个按钮
- [ ] 点完的结果落进了存档或账目，并在测试里查了
- [ ] 不满足条件时有提示
- [ ] 界面文字是玩家听得懂的简体中文，不露内部标记
- [ ] 三个版本都能用（claude.ai 版、网页版、桌面版的差异，搜 `DS_DIRECT`、`claudemode`）
