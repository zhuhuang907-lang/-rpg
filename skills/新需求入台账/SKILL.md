# 新需求入台账

## 步骤

1. 在 `REQUIREMENTS.md` 搜有没有同类条目；有就补在那条下面（写「补」和日期），没有就新开。
2. 编号接最后一条往后（`grep '^### R-' REQUIREMENTS.md | tail -1`）。
3. 照格式写（提交检查会查三栏齐不齐）：

```markdown
### R-编号 一句话标题
- 来源：日期 玩家：「原话，一字不改」
- 玩家验收：
  - 玩家能看到、能点到、能感觉到的结果
- 自动验收：测试文件名（防什么）
- 状态：未做
```

4. 玩家原话照字面理解；拿不准的，照他最近一次明说的意思，并在汇报里说明你怎么理解的。
5. 台账**一条不删**；做完只改「状态」。

## 检查

- [ ] 原话照抄
- [ ] 玩家验收写的是玩家能感知的结果，不是代码细节
- [ ] 至少一条自动验收
