# 任职年表

「哪年谁在哪一国任什么官」，开发时整理，游戏排朝堂、名册时照表先坐位子（任务六，R-225、R-226）。表里没有的位子：空着标史阙，或由模型补小位子并标虚构。

| 文件 | 年代 | 来源 | 规模 |
|---|---|---|---|
| `ming-cbdb.json` | 晚明 1573–1644 | 哈佛中国历代人物传记资料库（CBDB），非商业用途 | 5290 人、6617 条 |
| `wudai-cbdb.json` | 唐末五代十国 860–979 | 同上，照每条任职的朝代码分政权 | 2598 人条、4487 条 |
| `tongjian-184-960.json` | 汉末三国、两晋十六国、南北朝、隋唐、五代 184–960 | 资治通鉴（本仓库原文库）逐年摘「以某为某官」，每条注卷数；人名照哈佛库人名表核 | 1584 人条、2136 条 |

生成：`scripts/cbdb_tenure.py`（哈佛库，原库不进仓库）、`scripts/tongjian_posts.py`（通鉴；定年 `scripts/tongjian_years.py`）。简体由程序转换。

已知局限（照实写）：
- 通鉴只记任命、不记离任：任期算到下一回任命，最多六年；同一年份每国表上通常只有十几到几十人——这就是史书留下的量，南北朝、十六国尤其少。
- 通鉴多不写国号：政权照「明写的复合国号 → 哈佛库朝代 → 句中单字国号 → 正史分南北（魏书北齐书周书 / 宋书南齐书梁书陈书）→ 同人十年内的写法」逐层定，仍可能有错。
- 人名照「末二字、复姓三字」切，对不上哈佛库的偶有切错。
