历史模拟 · 怎么玩
====================

1. 双击 HistoryRPG.exe。会弹出一个游戏窗口（用的是电脑自带的 Edge 或 Chrome）。
2. 第一次玩：在首页粘贴一个 DeepSeek 的 Key，点「保存」。只要填一次。
   没有 Key：去 https://platform.deepseek.com/api_keys 注册后生成一个。
3. 在输入框写一句话，比如「万历年间苏州的绣娘」，回车。
   不想想，就点「随便来一个」。
4. 游戏会先查这段历史（半分钟到两分钟），然后你就醒过来了。

关掉游戏窗口就退出游戏。存档自动保存在 game\saves 里，下次打开首页点「继续」。

· 查史默认用免费的维基百科；想查得更全，可以在右上「设置」里填博查（bochaai.com）的 Key。
· 不填任何 Key 也能玩：首页最下面「现成剧本」。
· 打不开：看 game\data\server.log 最后几行，截图发给作者。
· 换电脑时把整个文件夹拷过去就行（Key 在 game\data\config.json，不要发给别人）。
